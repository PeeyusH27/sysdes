You are given an array of **positive** integers `nums` and a positive integer `target`.

Return the length of the **shortest contiguous subarray** whose sum is **greater than or equal to** `target`. If no subarray reaches the target, return `0`.

### Constraints

- `1 <= target <= 10^9`
- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^4`
