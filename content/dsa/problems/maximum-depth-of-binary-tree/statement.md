You are given the `root` of a binary tree. Return its **maximum depth**: the number of nodes on the longest path that starts at the root and goes down to a leaf (a node with no children).

An empty tree (`root` is `null`) has depth `0`, and a tree with a single node has depth `1`.

Trees in the examples are written in level order: the values row by row, left to right, with `null` where a child is missing. Your function receives the root `TreeNode` (with `val`, `left` and `right`), not the array.

### Constraints

- The tree has between `0` and `10^4` nodes.
- `-100 <= Node.val <= 100`
