You are given an array `nums` of **distinct** integers sorted in ascending order, and an integer `target`.

If `target` is in the array, return its index. If it isn't, return the index where it **would be inserted** so that the array stays sorted. That index can be `nums.length` when the target is larger than every element.

Your solution must run in **O(log n)** time.

### Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i], target <= 10^4`
- The values in `nums` are distinct and sorted in ascending order.
