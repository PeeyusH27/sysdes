Given an integer array `nums`, find the **contiguous, non-empty subarray** whose elements have the largest product, and return that product.

The array can contain negative numbers and zeros, so the best subarray is not always the longest one, and the answer may be `0` or negative (for example when the array is a single negative number).

### Constraints

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- The product of any subarray fits in a 32-bit integer.
