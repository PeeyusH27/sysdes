You are given the `root` of a binary tree. **Invert** it: turn it into its mirror image, so that at every node the left and right children trade places. Return the root of the inverted tree.

You may rearrange the existing nodes in place or build new ones; the tests read the tree you return.

Trees are shown in level order (row by row, left to right, `null` for a missing child), but your function receives and returns `TreeNode` objects.

### Constraints

- The tree has between `0` and `100` nodes.
- `-100 <= Node.val <= 100`
