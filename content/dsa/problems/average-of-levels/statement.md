Given the `root` of a binary tree, return an array with the **average value of the nodes on each level**, starting with the root's level and going down.

Answers within `10^-5` of the exact average are accepted, so ordinary floating-point division is fine. If the tree is empty, return an empty array.

### Constraints

- The tree has between `0` and `10^4` nodes.
- `-2^31 <= Node.val <= 2^31 - 1`
