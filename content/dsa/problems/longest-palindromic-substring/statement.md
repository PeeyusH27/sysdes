Given a string `s`, return its **longest palindromic substring**: the longest contiguous piece that reads the same from left to right as from right to left.

If several substrings share the longest length (for `"babad"`, both `"bab"` and `"aba"`), return any one of them.

### Constraints

- `1 <= s.length <= 1000`
- `s` consists of lowercase English letters.
