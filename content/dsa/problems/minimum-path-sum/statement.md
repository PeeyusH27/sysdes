You are given an `m × n` grid of non-negative integers, where `grid[r][c]` is the cost of stepping on cell `(r, c)`.

Start on the top-left cell and finish on the bottom-right cell, moving only **right** or **down** one cell at a time. The cost of a path is the sum of every cell it visits, including the first and the last. Return the smallest possible cost.

### Constraints

- `1 <= m, n <= 200`
- `0 <= grid[r][c] <= 100`
