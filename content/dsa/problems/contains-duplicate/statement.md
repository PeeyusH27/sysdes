Given an integer array `nums`, return `true` if **some value appears at least twice**, and `false` if every element is distinct.

Only the values matter, not their positions: `[5, 1, 5]` has a duplicate even though the two 5s are not neighbours.

### Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
