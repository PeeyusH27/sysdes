Given an integer array `nums`, move all `0`s to the end of it while keeping the **relative order** of the non-zero elements.

Do this **in place**: modify `nums` directly and don't return anything (the tests read `nums` after your function returns). Don't make a copy of the array.

### Constraints

- `1 <= nums.length <= 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
