You are given an integer array `nums` sorted in **non-decreasing** order (values may repeat) and an integer `target`.

Return a pair `[first, last]`: the index of the first occurrence of `target` and the index of its last occurrence. If `target` does not appear, return `[-1, -1]`.

Your solution must run in **O(log n)** time, even when the target fills most of the array.

### Constraints

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i], target <= 10^9`
- `nums` is sorted in non-decreasing order.
