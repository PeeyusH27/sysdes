Given an integer array `nums`, return an array `answer` of the same length where `answer[i]` is the **product of every element of `nums` except `nums[i]`**.

You may **not use division**, and the algorithm should run in O(n) time. Try to use only O(1) extra space besides the output array.

### Constraints

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- The product of any prefix or suffix of `nums` fits in a 32-bit integer.
