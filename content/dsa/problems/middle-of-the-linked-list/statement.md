You are given the `head` of a non-empty singly linked list. Return its **middle node**.

When the list has an even number of nodes there are two middle nodes: return the **second** one.

Return the node itself, not its value. The tests read the list starting from the node you return, so the middle of `1 → 2 → 3 → 4 → 5` shows up as `[3, 4, 5]`.

### Constraints

- The list has between `1` and `100` nodes.
- `-100 <= Node.val <= 100`
