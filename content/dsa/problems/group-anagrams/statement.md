You are given an array of strings `strs`. Group together the words that are **anagrams** of each other (they use the same letters, each the same number of times), and return the list of groups.

Every word belongs to exactly one group. If a word appears several times, each copy goes into its group. You may return the groups in any order, and the words inside each group in any order.

### Constraints

- `1 <= strs.length <= 10^4`
- `0 <= strs[i].length <= 100`
- `strs[i]` contains lowercase English letters only (it may be the empty string).
