You are given an array `nums` of `n` **distinct** integers, each taken from the range `0` to `n` (both ends included). The range has `n + 1` numbers and the array has only `n`, so exactly one number of the range is missing. Return it.

Aim for O(n) time and O(1) extra space.

### Constraints

- `1 <= n <= 10^4`, where `n === nums.length`
- `0 <= nums[i] <= n`
- All values in `nums` are distinct.
