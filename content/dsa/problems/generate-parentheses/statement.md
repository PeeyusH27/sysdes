Given `n`, the number of pairs of parentheses, return every string of `n` opening brackets `"("` and `n` closing brackets `")"` that is **balanced**.

A string is balanced when every `")"` closes an earlier, still-open `"("`: reading left to right, the number of closing brackets never exceeds the number of opening ones, and at the end they are equal. Return each balanced string once, in any order.

### Constraints

- `1 <= n <= 8`
