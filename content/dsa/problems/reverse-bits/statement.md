You are given an integer `n` that represents a **32-bit unsigned** integer, between `0` and `2^32 - 1`. Reverse the order of its 32 bits, leading zeros included: bit 0 (the lowest) becomes bit 31 (the highest), bit 1 becomes bit 30, and so on.

Return the result as a 32-bit **unsigned** integer, that is, a number between `0` and `2^32 - 1`. A negative answer is not accepted.

### Constraints

- `0 <= n <= 2^32 - 1`
