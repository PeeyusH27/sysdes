You are given two strings `s1` and `s2`. Return `true` if `s2` contains a **substring** (a contiguous piece) that is a **rearrangement** of `s1`, and `false` otherwise.

A rearrangement uses exactly the same letters as `s1`, each the same number of times, in any order. `s1` itself counts as one of its rearrangements.

### Constraints

- `1 <= s1.length, s2.length <= 10^4`
- `s1` and `s2` contain lowercase English letters only.
