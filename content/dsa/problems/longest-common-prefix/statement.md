Given an array of strings `strs`, return the **longest common prefix**: the longest string that every element of `strs` starts with.

If the strings have no common prefix (for example, their first characters differ, or one of them is empty), return the empty string `""`.

### Constraints

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- Every string contains lowercase English letters only.
