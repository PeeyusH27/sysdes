Given an integer array `nums`, find the **contiguous**, non-empty subarray (a run of one or more neighbouring elements) with the largest sum, and return that sum.

The subarray must contain at least one element, even when every number is negative.

### Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- Aim for O(n) time: checking every subarray is O(n²).
