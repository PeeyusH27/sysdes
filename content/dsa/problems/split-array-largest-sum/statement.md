You are given an array `nums` of non-negative integers and an integer `k`.

Split `nums` into exactly `k` **non-empty, contiguous** pieces (every element belongs to exactly one piece, and the pieces keep the array's order). The cost of a split is the **largest** sum among its pieces.

Return the smallest cost any split can achieve.

### Constraints

- `1 <= nums.length <= 1000`
- `0 <= nums[i] <= 10^6`
- `1 <= k <= min(50, nums.length)`
