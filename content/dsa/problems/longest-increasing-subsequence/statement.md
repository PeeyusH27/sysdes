Given an integer array `nums`, return the length of its longest **strictly increasing subsequence**.

A subsequence is what remains after deleting any number of elements (possibly none) without changing the order of the rest. It doesn't have to be contiguous. "Strictly increasing" means every element is larger than the one before it, so equal values can't be neighbours in it.

### Constraints

- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`
