You are given a string `s` and a list of words `wordDict`. Return `true` if `s` can be cut into a sequence of one or more pieces, where every piece is a word from `wordDict`. Otherwise return `false`.

The pieces must cover `s` completely and in order, with nothing left over. The same word may be used any number of times, and words you don't need can be ignored.

### Constraints

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` and every word contain only lowercase English letters; the words are all different.
