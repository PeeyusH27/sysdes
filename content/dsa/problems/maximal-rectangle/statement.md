You are given a grid made only of `0` and `1`. Find the **largest rectangle that contains only 1s** and return its area (the number of cells). If the grid has no `1`, return `0`.

The rectangle must be axis-aligned: it covers a block of consecutive rows and consecutive columns.

### Constraints

- `1 <= rows, columns <= 200`
- Every cell is `0` or `1`.
