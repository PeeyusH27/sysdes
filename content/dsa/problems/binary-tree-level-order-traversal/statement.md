Given the `root` of a binary tree, return its values **level by level**: an array of arrays where the first inner array holds the root's value, the second holds the values one level down, and so on. Within a level, list the values from left to right.

Return an empty array for an empty tree.

### Constraints

- The tree has between `0` and `2000` nodes.
- `-1000 <= Node.val <= 1000`
