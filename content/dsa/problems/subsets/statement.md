Given an array `nums` of **distinct** integers, return every possible **subset** of it (its power set).

A subset is any selection of the numbers, including the empty selection and the whole array. Two subsets with the same numbers are the same subset, so each must appear exactly once. You may return the subsets in any order, and the numbers inside each subset in any order.

### Constraints

- `0 <= nums.length <= 10`
- `-10 <= nums[i] <= 100`
- All values in `nums` are different.
