Given the root of a **binary search tree** and an integer `k`, return the `k`-th smallest value among all the node values. Counting starts at 1, so `k = 1` asks for the minimum.

The tree contains at least `k` nodes. Return a number.

### Constraints

- The tree has `n` nodes, with `1 <= k <= n <= 10^4`.
- `0 <= Node.val <= 10^4` (the tests also use negative values).
- All values are distinct.
