Given two strings `text1` and `text2`, return the length of their longest **common subsequence**. If they have no common subsequence, return `0`.

A subsequence of a string is what remains after deleting some characters (possibly none) without changing the order of the others: `"one"` is a subsequence of `"stone"`, but `"eno"` is not. A common subsequence appears, in this sense, in both strings.

### Constraints

- `0 <= text1.length, text2.length <= 1000`
- Both strings contain only lowercase English letters.
