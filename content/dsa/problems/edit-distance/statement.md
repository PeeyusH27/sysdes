Given two strings `word1` and `word2`, return the **fewest operations** needed to turn `word1` into `word2`. Each operation changes one character:

- **insert** a character anywhere,
- **delete** a character,
- **replace** a character with a different one.

### Constraints

- `0 <= word1.length, word2.length <= 500`
- Both strings contain only lowercase English letters.
