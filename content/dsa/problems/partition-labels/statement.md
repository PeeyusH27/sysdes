You are given a string `s` of lowercase English letters. Cut it into as many pieces as possible so that every letter appears in **at most one** piece. Joining the pieces in order must give back `s`, so a piece is always a contiguous chunk of the string.

Return an array with the length of each piece, from left to right.

### Constraints

- `1 <= s.length <= 500`
- `s` consists of lowercase English letters.
