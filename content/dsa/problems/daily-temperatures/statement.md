You are given an array `temperatures`, where `temperatures[i]` is the temperature on day `i`.

Return an array `answer` of the same length, where `answer[i]` is the number of days you have to wait after day `i` until a **strictly warmer** day. If no later day is warmer, `answer[i]` is `0`.

### Constraints

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`
