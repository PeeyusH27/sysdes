Given an array `nums` of **distinct** integers, return every possible **permutation**: every way to arrange all of its numbers in a row.

An array of `n` distinct numbers has `n!` permutations, and each must appear exactly once. You may return them in any order (but the order of numbers inside each permutation is, of course, what makes it that permutation).

### Constraints

- `1 <= nums.length <= 6`
- `-20 <= nums[i] <= 20`
- All values in `nums` are different.
