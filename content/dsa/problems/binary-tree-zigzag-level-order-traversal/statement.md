Given the `root` of a binary tree, return its values level by level in **zigzag order**: the first level from left to right, the second from right to left, the third from left to right again, and so on, alternating at every level.

The result is an array of arrays, one inner array per level, top level first. Return an empty array for an empty tree.

### Constraints

- The tree has between `0` and `2000` nodes.
- `-100 <= Node.val <= 100`
