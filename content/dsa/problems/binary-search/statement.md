You are given an array `nums` of **distinct** integers sorted in ascending order, and an integer `target`.

Return the index of `target` in `nums`, or `-1` if it does not appear.

Your solution must run in **O(log n)** time, so checking the elements one by one is not the intended approach.

### Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i], target <= 10^4`
- The values in `nums` are distinct and sorted in ascending order.
