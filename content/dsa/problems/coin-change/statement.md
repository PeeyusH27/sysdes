You are given an array `coins` of distinct coin values and a target `amount`. You have an unlimited number of coins of each value.

Return the **fewest coins** whose values add up to exactly `amount`. If no combination of coins makes the amount, return `-1`. An amount of `0` needs `0` coins.

### Constraints

- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 10^4`, all different
- `0 <= amount <= 10^4`
