You are given the `head` of a linked list and an integer `n`. Remove the `n`-th node **counted from the end** of the list (the last node is the 1st from the end) and return the head of the resulting list.

Try to do it in **one pass** over the list.

### Constraints

- The list has `sz` nodes, `1 <= sz <= 30`.
- `0 <= Node.val <= 100`
- `1 <= n <= sz`
