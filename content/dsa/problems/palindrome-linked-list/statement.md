You are given the `head` of a singly linked list. Return `true` if its values read the same from front to back as from back to front, and `false` otherwise.

The list only links forward, so you can't walk it backwards directly. Copying the values into an array works; try to solve it in O(n) time with **O(1) extra space**. You may rewire the list's `next` pointers while you work.

### Constraints

- The list has between `1` and `10^5` nodes.
- `0 <= Node.val <= 9`
