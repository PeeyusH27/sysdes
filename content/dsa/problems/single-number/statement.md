You are given a non-empty array of integers `nums`. Every value in it appears **exactly twice**, except for one value that appears **exactly once**. Return that value.

Your solution should run in linear time and use only constant extra space.

### Constraints

- `1 <= nums.length <= 3 * 10^4`
- `-3 * 10^4 <= nums[i] <= 3 * 10^4`
- Every value appears exactly twice, except one value that appears exactly once.
