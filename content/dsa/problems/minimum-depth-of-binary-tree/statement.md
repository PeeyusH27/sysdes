Given the `root` of a binary tree, return its **minimum depth**: the number of nodes on the shortest path from the root down to the nearest **leaf**.

A leaf is a node with no children. A node that has only one child is not a leaf, so a path can't stop there.

An empty tree has minimum depth `0`.

### Constraints

- The tree has between `0` and `10^5` nodes.
- `-1000 <= Node.val <= 1000`
