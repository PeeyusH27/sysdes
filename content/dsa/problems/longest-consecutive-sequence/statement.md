You are given an unsorted array of integers `nums`. Return the length of the **longest run of consecutive integers** whose values all appear in `nums`, such as `4, 5, 6, 7`.

The values don't need to be next to each other in the array, and a value that appears several times counts once. An empty array has a longest run of `0`.

Your algorithm should run in **O(n)** time.

### Constraints

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
