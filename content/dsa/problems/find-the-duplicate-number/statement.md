You are given an array `nums` of `n + 1` integers, where every value is between `1` and `n` inclusive. There are more slots than possible values, so some value must repeat. Here **exactly one value** repeats, although it may appear more than twice.

Return that repeated value.

You must not modify `nums` (so no sorting it and no marking values in place), and you should use only **O(1) extra space**.

### Constraints

- `1 <= n <= 10^5`
- `nums.length === n + 1`
- `1 <= nums[i] <= n`
- Exactly one value appears two or more times.
