Given the `root` of a binary tree, return the length of its **diameter**: the longest path between any two nodes, measured in **edges** (the number of parent-child links along the path).

The path does not have to pass through the root. It may climb up from one node to some ancestor and come back down the other side to a second node, but it can't visit a node twice.

A tree with zero or one node has diameter `0`.

### Constraints

- The tree has between `0` and `10^4` nodes.
- `-100 <= Node.val <= 100`
