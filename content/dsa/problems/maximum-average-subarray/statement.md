You are given an array of integers `nums` and an integer `k`.

Among all **contiguous** subarrays of length exactly `k`, find the one with the largest average and return that average. Answers within `10^-5` of the exact value are accepted.

### Constraints

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
